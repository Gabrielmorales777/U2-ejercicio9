# U2-ejercicio9
### Estación Meteorológica y Sensores Ambientales

Este ejercicio consiste en desarrollar un sistema en Java que simula el funcionamiento de una estación meteorológica que se comunica con múltiples sensores ambientales.

La clase `Sensor` representa sensores de diferentes tipos, como temperatura, humedad y presión, y utiliza el método `obtenerLectura()` para generar valores numéricos simulados. Por su parte, la clase `EstacionMeteorologica` mantiene una lista de sensores y, mediante el método `generarReporteClimatico()`, solicita las lecturas de cada uno y muestra los resultados por consola.

El objetivo es practicar la **comunicación entre objetos**, el uso de listas, la invocación de métodos y la colaboración entre clases en Java.
